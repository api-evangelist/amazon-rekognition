# Amazon Rekognition

> Amazon Rekognition is a cloud-based computer vision service that adds image and video analysis to applications, including label/object detection, facial analysis, face comparison and search, celebrity recognition, text detection, content moderation, custom labels, face liveness detection, protective-equipment detection, and streaming/stored video analysis using deep learning. Accessed over an AWS JSON 1.1 protocol endpoint (rekognition.amazonaws.com) with AWS Signature Version 4 authentication.
